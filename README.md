# Mobile Computing Project

## Backend & Database Deployment

This project uses a cloud-hosted backend and database:
*   **Backend**: Deployed on [Render.com](https://render.com)
*   **Database**: PostgreSQL deployed on [Neon.tech](https://neon.tech)

### Important - before running the app

The backend is hosted on a Render free tier instance, which **spins down (sleeps) after periods of inactivity**. When the instance is asleep, the first request will fail or time out while the server wakes up.

**To ensure the mobile app works correctly:**

1.  Open your web browser.
2.  Navigate to **[https://mobile-computing-i3hs.onrender.com](https://mobile-computing-i3hs.onrender.com)**.
3.  **Wait a few seconds** for the page to load (it may take up to a minute if the instance was sleeping).
4.  Once the page loads, the backend is active. You can now launch and use the mobile app.
